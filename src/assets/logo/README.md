# Logo de Medra

Opción 2 de `docs/propuestas-logo.html` (cruz médica con pulso). Color principal
`#2383C2`; tipografía Manrope (800 para "Medra", 700 para "SISTEMA INTEGRAL"),
convertida a trazos: los SVG no dependen de ninguna fuente.

| Archivo | Uso |
|---|---|
| `medra-logo-claro.svg` | Símbolo + "Medra", sobre fondo claro |
| `medra-logo-oscuro.svg` | Símbolo + "Medra", sobre fondo oscuro (azul marino, gris) |
| `medra-logo-blanco.svg` | Símbolo + "Medra" en blanco, sobre el azul `#2383C2` (menú lateral) |
| `medra-logo-sistema-integral-{claro,oscuro,blanco}.svg` | Con "SISTEMA INTEGRAL" debajo |
| `medra-simbolo.svg` / `-oscuro.svg` / `-blanco.svg` | Solo el símbolo |
| `png/*-512.png`, `png/*-1024.png` | Los mismos, en PNG con fondo transparente (documentos, correos, presentaciones) |

Favicon e íconos de la app (en `public/`): `favicon.svg`, `favicon.ico`
(16, 32 y 48 px; el de 16 px va sin el pulso para que se reconozca),
`apple-touch-icon.png` (180 px, fondo lleno), `icon-192.png`, `icon-512.png`
y `site.webmanifest`.
